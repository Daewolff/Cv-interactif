# Portfolio David Genty — version responsive

Cette version conserve le rendu desktop validé et ajoute uniquement des optimisations sous 1024 px pour tablettes et téléphones.

Fichiers principaux :
- index.html
- cv.html
- cv-pdf.html
- styles.css
- cv.css
- pdf.css
- script.js
- cv.js
- CV_David_GENTY.pdf

Les règles responsive ajoutées sont regroupées en fin des fichiers CSS pour être faciles à repérer et à modifier.
