# CV interactif — V2.6 complète

Version locale du portfolio de David Genty.

## Fichiers principaux
- `index.html` : portfolio principal
- `cv.html` : CV digital interactif No-Code / automatisation / IA appliquée
- `styles.css` : design global du portfolio
- `script.js` : interactions communes
- `cv.css` : design spécifique du CV digital
- `cv.js` : interactions du CV (workflow, filtres de compétences, parcours dynamique, mode synthèse)

## Lancer en local
Ouvrir `index.html` ou directement `cv.html` dans un navigateur moderne.

## Publication
Aucune publication automatique n'est effectuée. Le dossier peut être testé en local puis envoyé sur GitHub Pages plus tard.
